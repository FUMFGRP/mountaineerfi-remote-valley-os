# सञ्चार — विकेन्द्रीकृत मेस सञ्जाल

**दुर्गम क्षेत्रका लागि भरपर्दो, समुदायको स्वामित्वको जडान। सेलुलर टावर छैन। स्याटलाइट बिल छैन। लचिलो मेस मात्र।**

---

## समस्या

दुर्गम हिमाली समुदायहरू एकभन्दा बढी तरिकाले **ग्रिडबाट बाहिर** छन्। सेलुलर कभरेज विरल वा छैन। स्याटलाइट इन्टरनेट महँगो। नतिजा:

- बजार मूल्य र मौसम पूर्वानुमानमा पहुँच छैन
- टेलिमेडिसिन वा टाढाको स्वास्थ्य परामर्श छैन
- आपत्कालीन कल असम्भव
- बालबालिकाले डिजिटल शिक्षण स्रोत पाउँदैनन्
- समुदाय बाहिरी संसारलाई अदृश्य छ
- सेन्सरको निगरानी डाटा उपत्यका बाहिर जाँदैन

परम्परागत समाधान (टावर-आधारित सेलुलर, फाइबर) कठिन भूभागमा कम घनत्वको जनसंख्याका लागि धेरै महँगो छ।

---

## समाधान

एउटा **विकेन्द्रीकृत वायरलेस मेस सञ्जाल** — हरेक नोडले अर्कोलाई डाटा रिले गर्छ, जसले उपत्यकाभर आत्म-निको हुने सञ्चार जाल बनाउँछ।

### मेस सञ्जाल कसरी काम गर्छ

परम्परागत सञ्जालमा हरेक डिभाइसले केन्द्रीय टावरसँग कुरा गर्छ। मेस सञ्जाल **वितरित** हुन्छ। हरेक नोडले दायराभित्रका हरेक नोडसँग कुरा गर्न सक्छ। एउटा नोड बिग्रँदा डाटा स्वतः अर्को मार्गबाट जान्छ। सञ्जाल आफै निको हुन्छ।

```
       ┌───────────┐
       │  Node A   │────┐
       │ (Village) │    │
       └───────────┘    │     ┌───────────┐
                        ├─────│  Node B   │
       ┌───────────┐    │     │  (Ridge)  │
       │  Node C   │────┘     └─────┬─────┘
       │ (Farm)    │               │
       └───────────┘               │     ┌───────────┐
                                   ├─────│  Node D   │
       ┌───────────┐               │     │ (Hub)     │
       │  Node E   │───────────────┘     └─────┬─────┘
       │ (School)  │                          │
       └───────────┘                          │
                                         ┌────▼────┐
                                         │ Internet │
                                         │ Gateway  │
                                         └─────────┘
```

### प्रविधि स्ट्याक

| तह | प्रविधि | उद्देश्य |
|---|---|---|
| लामो दायराको ब्याकबोन | LoRa (९१५ MHz) | कम शक्ति, लामो दायरा (१०-१५ किमी लाइन-अफ-साइट) सेन्सर डाटा, पाठ सन्देश |
| मध्यम दायराको डाटा | Wi-Fi mesh (२.४/५ GHz) | उच्च ब्यान्डविथ स्थानीय जडान (वेब, आवाज, भिडियो) |
| इन्टरनेट गेटवे | Starlink वा फाइबर (उपलब्ध भए) | विश्वव्यापी इन्टरनेट जडान |
| अफलाइन सर्भर | हबमा स्थानीय सर्भर | स्थानीय LLM, विकी, क्यास सामग्री, ड्यासबोर्ड |

## नोडहरू

### नोड प्रकार

| नोड प्रकार | स्थान | हार्डवेयर | उद्देश्य |
|---|---|---|---|
| गाउँ नोड | केन्द्रीय गाउँ स्थान | LoRa + Wi-Fi mesh, सौर्य | सामुदायिक जडान |
| शिखर रिले | उपत्यकाबीचको उच्च बिन्दु | LoRa रिले मात्र, सौर्य | हिमालमाथि दायरा विस्तार |
| हब नोड | प्रशोधन केन्द्र, आवास | पूर्ण स्ट्याक + स्थानीय सर्भर | इन्टरनेट गेटवे, LLM, ड्यासबोर्ड |
| खेत नोड | दुर्गम कृषि क्षेत्र | LoRa + सानो Wi-Fi | सेन्सर डाटा, मौसम पहुँच |
| चार्जिङ स्टेशन नोड | हरेक EV स्टेशन | LoRa + Wi-Fi mesh | यात्रु जडान, सेन्सर डाटा |

## सञ्जालले के सम्भव बनाउँछ

### समुदायका सदस्यका लागि

| अनुप्रयोग | फाइदा |
|---|---|
| आवाज कल र पाठ | अन्य गाउँका परिवारसँग जोडिने |
| बजार मूल्य | बजार जानु अघि मूल्य जाँच्ने |
| मौसम पूर्वानुमान | रोपाइँ, फसल र यात्रा योजना |
| आपत्कालीन सूचना | चेतावनी प्रसारण (बाढी, आँधी, आगलागी) |
| सामुदायिक सन्देश | गाउँका घोषणा, कार्यक्रम सूचना |

### ब्लुप्रिन्टका प्रणालीका लागि

| अनुप्रयोग | बग्ने डाटा |
|---|---|
| ऊर्जा निगरानी | सौर्य उत्पादन, ब्याट्री अवस्था, जल निर्गत, लोड डाटा |
| पानी गुणस्तर | प्रवाह दर, धमिलोपन, pH, UV अवस्था |
| प्रशोधन केन्द्र | उत्पादन मात्रा, भण्डार, अर्डर स्थिति |
| EV चार्जिङ | स्टेशन प्रयोग, ब्याट्री स्वाप भण्डार |
| सेन्सर सञ्जाल | तापक्रम, आर्द्रता, वर्षा, माटोको आर्द्रता |
| मर्मत सूचना | प्रणालीलाई ध्यान चाहिँदा स्वतः सूचना |

### शिक्षा र स्वास्थ्यका लागि

| अनुप्रयोग | फाइदा |
|---|---|
| टेलिमेडिसिन | जिल्ला अस्पतालका डाक्टरसँग भिडियो परामर्श |
| टाढाको शिक्षा | क्यास शैक्षिक सामग्री, भर्चुअल कक्षा |
| स्थानीय LLM | नेपालीमा प्राविधिक प्रश्नको जवाफ दिने AI सहायक |
| ज्ञान आधार | सबै परियोजना कागजात अफलाइन पहुँचयोग्य |

---

## स्थानीय LLM

हब नोडको स्थानीय सर्भरमा एउटा **सानो भाषा मोडेल** चल्छ। यो:

- **परियोजना कागजातमा तालिम** — सञ्चालक पुस्तिका, समस्या समाधान गाइड, तालिम सामग्री
- **बहुभाषिक** — मुख्यतया नेपाली, अंग्रेजी फलब्याकसहित
- **आवाज सक्षम** — कम साक्षरता भएका समुदाय सदस्यका लागि
- **अफलाइन** — प्रश्नको जवाफ दिन इन्टरनेट आवश्यक पर्दैन
- **स्वयं-सुधारक** — नजवाफ भएका प्रश्न अभिलेख गरी कागजात सुधार्न प्रयोग

**उदाहरण प्रश्न:**
- "एक्सट्रुडर कसरी सफा गर्ने?"
- "ब्याट्री कति छ?"
- "पानीको pH कति हुनुपर्छ?"

LLM प्राविधिकको विकल्प होइन। यो पहिलो-स्तरको स्रोत हो, जसले सामान्य प्रश्नका लागि टाढाका विज्ञसँग सम्पर्क गर्ने आवश्यकता घटाउँछ।

## तालिम पाइपलाइन

### आधार (३ महिना)
- आधारभूत डिभाइस सञ्चालन (WiFi पहुँच, सन्देश प्रयोग)
- सञ्जाल समस्या रिपोर्ट (नोड अफलाइन, ढिलो जडान)
- शक्ति व्यवस्थापन (सौर्य प्यानल सफा, ब्याट्री जडान)

### सञ्चालक (६ महिना)
- ड्यासबोर्डबाट सञ्जाल अवस्था निगरानी
- नोड मर्मत (सौर्य प्यानल सफा, जडान जाँच, रिबुट)
- समुदाय सदस्यलाई जडान समस्यामा सहयोग
- प्रयोग ढाँचा अभिलेख

### प्राविधिक (१२ महिना)
- नयाँ नोड जडान र कन्फिगर
- हार्डवेयर खराबीको निदान र मर्मत
- उत्तम कभरेजका लागि एन्टेना स्थिति ट्युनिङ
- फर्मवेयर र सफ्टवेयर अद्यावधिक
- इन्टरनेट गेटवे व्यवस्थापन
- आधार र सञ्चालक सिकाइकर्तालाई तालिम

### मास्टर ट्रेनर (निरन्तर)
- नयाँ क्षेत्रका लागि मेस सञ्जाल डिजाइन
- उत्तम कभरेजका लागि नोड स्थान योजना
- तालिम पाठ्यक्रम विकास र मर्मत
- सञ्चालक र प्राविधिकलाई प्रमाणित गर्ने

## अन्य मोड्युलसँग एकीकरण

| मोड्युल | कसरी जोडिन्छ |
|---|---|
| **ऊर्जा** | सेन्सरले माइक्रो-ग्रिड अवस्था रिपोर्ट गर्छ; नोड सौर्य/ब्याट्रीबाट चल्छन् |
| **पानी** | पानी गुणस्तर सेन्सरले मेस मार्फत रिपोर्ट गर्छ |
| **खाद्य** | उत्पादन डाटा, भण्डार, अर्डर मेस मार्फत पठाइन्छ |
| **ट्र्यास-टु-टेक** | उत्पादन अभिलेख, मर्मत अनुरोध |
| **लजिस्टिक्स** | EV चार्जिङ स्टेशन डाटा, यातायात तालिका |
| **स्वास्थ्य** | टेलिमेडिसिन, स्वास्थ्य अभिलेख, आपत्कालीन सूचना |

मेस सञ्जाल ब्लुप्रिन्टको **स्नायु प्रणाली** हो। यसले अन्य हरेक मोड्युलको डाटा बोक्छ र त्यसलाई उपयोगी बनाउँछ।

## प्राविधिक विशेषता

| प्यारामिटर | मान |
|---|---|
| LoRa दायरा (लाइन अफ साइट) | १०-१५ किमी |
| LoRa दायरा (हिमाली) | ३-८ किमी (भूभाग-निर्भर) |
| Wi-Fi mesh दायरा (प्रति नोड) | १००-३०० मिटर |
| डाटा दर (LoRa) | ५० kbps (सेन्सर डाटा, पाठका लागि पर्याप्त) |
| डाटा दर (Wi-Fi) | ५० Mbps सम्म (नोड क्लस्टरभित्र) |
| नोड शक्ति खपत | ५-१५W (सौर्य/ब्याट्री) |
| मेसमा अधिकतम नोड | १००+ (सैद्धान्तिक) |
| फ्रिक्वेन्सी ब्यान्ड | ९१५ MHz (LoRa), २.४/५ GHz (Wi-Fi) |

## खुला स्रोत

सबै मेस नोड डिजाइन — हार्डवेयर स्पेक, एन्टेना डिजाइन, फर्मवेयर, सर्भर सफ्टवेयर — खुला स्रोत इजाजतपत्र अन्तर्गत प्रकाशित छन्।

समुदायहरूले:
- सामान्य घटकबाट नोड बनाउन
- आफ्नो भूभागअनुसार एन्टेना डिजाइन अनुकूलन गर्न
- फर्मवेयर सुधार योगदान गर्न
- इजाजतपत्र शुल्क बिना तैनात गर्न

**जडान पूर्वाधार हो। यो बनाउने ज्ञान बाँडिनुपर्छ।**
